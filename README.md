# 📊 Financials Dashboard (Power BI Sample Data)

## 🔍 Overview

This project presents an interactive **Financials Dashboard** built using Power BI.
It analyzes sales, profit, and quantity across different countries, segments, and time periods using Power BI's sample dataset.

---

## 📊 Dashboard Highlights

* 💰 **Total Sales:** 118.73M
* 📈 **Total Profit:** 16.89M
* 📦 **Total Units Sold:** 1.13M

---

## 📌 Key Features

* Year-wise analysis of Sales, Profit, and Quantity
* Segment-wise performance breakdown (Government, Small Business, Enterprise, etc.)
* Country-wise sales visualization using map
* Quarterly trends to identify seasonal patterns
* Interactive filters (Country, Segment, Year, Quarter)

---

## 💡 Key Insights

* Government segment contributes the highest share of overall sales
* Sales and profit show strong growth from 2013 to 2014
* Quarter 4 has the highest performance across all metrics
* North America and Europe dominate sales distribution

---

## 🛠 Tools & Technologies
